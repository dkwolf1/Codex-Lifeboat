# Codex Lifeboat 3.4.3 — more reliable backups with active plugins

[Nederlands](../nl/releases/v3.4.3.md)

Codex Lifeboat 3.4.3 is a focused reliability update for Windows 10/11. It keeps
the same simple goal: carry Codex projects, chats, settings, and related local
data safely between computers.

## What changed

- New backups exclude the machine-specific `.codex/plugins` download cache and
  active plugin runtime, preventing locked plugin files from aborting a backup.
- Plugin configuration and user-created skills remain included and portable.
- Restore ignores plugin-runtime payloads in older backups and preserves the
  destination computer's local plugin runtime.
- Historical temporary chat attachments that Windows no longer permits reading
  are reported as notices instead of stopping the complete backup.
- Existing backup formats remain supported.

## Download

Download `Codex-Lifeboat-Windows-x64-Portable.zip`, extract it completely, and
start `Codex-Lifeboat.exe`. Do not run the application inside the ZIP file.

This remains a public testing release. Keep an independent copy of irreplaceable
data and report unexpected results through GitHub Issues.
