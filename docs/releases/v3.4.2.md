# Codex Lifeboat 3.4.2 — clearer interface and path details

[Nederlands](../nl/releases/v3.4.2.md)

Codex Lifeboat 3.4.2 keeps the same simple goal: carry Codex projects, chats,
settings, and related local data safely between Windows 10/11 computers.

## What changed

- A redesigned professional dashboard makes backup, restore, verification,
  recovery points, and diagnostics easier to find.
- Backup results now show clearer status, project, conversation, and size cards.
- Path-portability notices explain which local references are translated,
  preserved, excluded as machine state, or need review.
- Unknown path references remain included and do not block a valid backup or
  restore; only an old link may still require attention after moving computers.
- Local full paths stay private and are removed from saved or copied reports.
- The sidebar title now remains fully visible with Windows display scaling.

## Download

Download `Codex-Lifeboat-Windows-x64-Portable.zip`, extract it completely, and
start `Codex-Lifeboat.exe`. Do not run the application inside the ZIP file.

This remains a public testing release. Keep an independent copy of irreplaceable
data and report unexpected results through GitHub Issues.
