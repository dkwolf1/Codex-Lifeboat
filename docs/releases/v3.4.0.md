# Codex Lifeboat 3.4.0 — public testing release

[Nederlands](../nl/releases/v3.4.0.md)

Codex Lifeboat 3.4.0 is a major beta/release-candidate update for carrying local
Codex projects, conversations, skills, and portable settings between Windows
10/11 computers. It is an independent community project, not an official OpenAI
product.

## Download

Most users should download only:

`Codex-Lifeboat-Windows-x64-Portable.zip`

Extract the ZIP completely and run `Codex-Lifeboat.exe`. Python, installation,
and administrator rights are not required. `Codex-Lifeboat.exe` is also attached
separately for advanced users. Verify the files using `SHA256.txt`.

## Highlights

- Complete, independently verified backups of selected project directories.
- Recent, archived, pinned, project-linked, and projectless local conversations.
- Portable skills, settings, available attachments, and consistent SQLite snapshots.
- Pre-backup project inventory with paths, file counts, sizes, largest folders,
  and optional whole-project exclusion.
- Username-independent Windows paths plus reviewed external-drive, USB, and UNC mapping.
- Permanent project identities and backup lineage for A-to-B-to-A hand-offs.
- Read-only restore comparison showing conflicts, actions, and required disk space.
- Explicit per-chat and per-project conflict decisions; data is never silently merged.
- Transactional, SHA-256-verified project replacement with rollback after failure.
- Destination-only data retained by default, with reviewed archive or recoverable removal.
- Managed local recovery points that keep the two newest valid points by default.
- Clear measured/animated progress through hashing, analysis, preflight, and final checks.
- Complete English interface and documentation with Dutch translation.

## Safety and validation

- Source authentication and machine identity are never transferred.
- The destination login and machine identity are preserved.
- Every completed package passes independent validation before it receives its final name.
- Source, packaged executable, and freshly extracted ZIP each pass 66/66 checks and
  12/12 automated Windows compatibility scenarios.
- The EXE is not commercially code-signed, so Windows SmartScreen may warn.
- GitHub Actions publishes build-provenance attestations for all three release assets.
- Backups are not encrypted and can contain source code, Git history, `.env` files,
  API keys, and conversation content. Keep backup media secure.

## Public testing status

This release is intentionally marked as a pre-release while real-world evidence
is collected for Windows 10, a second Windows 11 computer, physical USB removal,
and complete PC-A-to-PC-B-to-PC-A hand-offs. Keep an independent copy of
irreplaceable data.

Read the [testing guide](https://github.com/dkwolf1/Codex-Lifeboat/blob/v3.4.0/docs/TESTING-GUIDE.md)
and report results with the **Compatibility test result** issue form. Never attach
a real backup or unsanitized logs.

## Compatibility

- Application: Windows 10/11 x64.
- Package reader: formats 2.0 through 2.4.
- New backups: format 2.4.
- Upgrade: replace the previous extracted application files with this release;
  existing backup packages do not need to be modified.
