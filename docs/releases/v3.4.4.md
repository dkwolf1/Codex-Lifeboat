# Codex Lifeboat 3.4.4 — stable release

[Nederlands](../nl/releases/v3.4.4.md)

Codex Lifeboat 3.4.4 is the first stable Windows 10/11 x64 release. It promotes
the tested 3.4 line after the complete real-world workflow succeeded on two
physical Windows 11 computers.

## Stable-release evidence

- Source, standalone EXE, and freshly extracted portable ZIP pass all 76 checks.
- All 12 automated Windows compatibility scenarios pass.
- A real PC A → PC B → PC A journey completed successfully.
- Create backup and independent Verify backup passed on both sides.
- Restore and Verify restore passed on both sides.
- Restored projects and conversations opened normally in Codex, and work continued.
- Destination authentication and machine identity remained local.
- Recovery points and automatic rollback protections remained active.

## Included reliability fixes

- Machine-specific downloaded plugin runtimes and caches are excluded, while
  plugin configuration and user-created skills remain portable.
- Historical attachments that are already missing or unreadable produce notices
  instead of aborting a complete backup.
- An inaccessible WindowsApps `winget.exe` alias no longer interrupts the optional
  online version check or blocks normal operation.
- Projects are staged, fully hash-verified, and atomically activated.
- Chats, archives, project links, available attachments, portable settings, and
  selected complete project directories travel together.
- Different usernames and portable Windows paths are translated at restore time.

## Download

Download `Codex-Lifeboat-Windows-x64-Portable.zip`, extract it completely, and run
`Codex-Lifeboat.exe`. Do not use GitHub's automatically generated source archives
unless you want to develop the application.

The release remains unsigned, backups remain unencrypted, and physical Windows 10
plus USB-removal-during-write testing remain additional coverage. Read the
[known limitations](../KNOWN-LIMITATIONS.md) before handling irreplaceable data.
