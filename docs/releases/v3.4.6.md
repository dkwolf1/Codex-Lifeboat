# Codex Lifeboat 3.4.6 — compressed conversation support

[Nederlands](../nl/releases/v3.4.6.md)

Codex Lifeboat 3.4.6 resolves the backup failure reported in issue #8 by adding
safe support for Codex `.jsonl.zst` conversation rollouts.

## Fixed

- Discovers both `.jsonl` and `.jsonl.zst` rollouts in active and archived chats.
- Reads compressed metadata and attachments through bounded-memory streaming.
- Preserves compressed rollout bytes, names, hierarchy, hashes, and thread IDs in
  the backup without modifying the source Codex profile.
- Rejects invalid, corrupt, or truncated Zstandard frames before a backup can be
  considered valid.
- Includes compressed rollouts in independent validation, diagnostics, lineage,
  duplicate resolution, and strict conversation-prefix comparison.
- Restores `.jsonl.zst` as `.jsonl.zst`, translates portable paths, updates the
  database rollout path, and verifies the restored thread ID.
- Keeps destination-only compressed conversations compressed when using the
  keep-both conflict choice.

## Validation

- All source self-tests pass, including mixed compressed and uncompressed chats.
- All tests pass from the packaged Windows executable.
- All 12 automated Windows compatibility scenarios pass.
- Regression coverage includes active and archived rollouts, byte-identical
  backup, source immutability, attachments, truncated frames, restore path
  translation, verification, and round-trip backup.
- SHA-256 checksums are included with the release artifacts.

## Download

Download `Codex-Lifeboat-Windows-x64-Portable.zip`, extract it completely, and
run `Codex-Lifeboat.exe`.

The executable remains unsigned. Physical confirmation with the reporter's
large mixed-format profile is recommended before closing issue #8.
