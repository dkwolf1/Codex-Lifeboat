# Codex Lifeboat 3.4.12 — Windows backup preview fixes

[Nederlands](../nl/releases/v3.4.12.md)

This update addresses both Windows backup failures reported in [issue #13](https://github.com/dkwolf1/Codex-Lifeboat/issues/13).

- Backup preview and copy now identify reserved Windows device names such as
  `NUL` and `NUL.txt` before accessing the entry. The preview activity log
  and the finished package's `reports/backup-report.json` list omitted entries.
  If a reserved name is a directory, its entire subtree is omitted. Rename the
  entry safely at the source before backing up if you need its contents.
- The root-level `.codex/app-server-control` socket and lock directory is
  excluded before metadata access, avoiding Windows error 1920. Restore keeps
  the destination's own runtime directory. A project subfolder with the same
  name is still included.
- The restored session index now uses atomic replacement with bounded retries
  when Windows temporarily denies access.

The regression tests exercise real reserved NTFS entries and a simulated
Windows error 1920. Download and fully extract
`Codex-Lifeboat-Windows-x64-Portable.zip`, then run `Codex-Lifeboat.exe`.
