# Codex Lifeboat 3.4.8 — paginated history consistency

[Nederlands](../nl/releases/v3.4.8.md)

Codex Lifeboat 3.4.8 prevents stale rollout byte offsets after restoring Codex
Desktop conversations that use paginated history.

## Fixed

- Excludes the derived `thread_history_1.sqlite` database and its WAL/SHM files
  from new portable backups.
- Ignores the same database files when restoring an older Lifeboat package.
- Resets the destination projection before installing rewritten rollout files.
  Codex can therefore rematerialize paginated history from byte offset zero
  instead of using offsets recorded for different rollout bytes.
- Preserves the destination projection in the managed recovery point so an
  interrupted restore can roll back byte-for-byte.
- Records the projection reset and removed-file count in the restore journal.

## Validation

- Added regression coverage for backup exclusion, 3.4.7 package compatibility,
  restore-time reset, recovery-copy preservation, and exact rollback.
- The full source suite passes all 88 checks and all 12 automated Windows
  compatibility scenarios.

## Download

Download `Codex-Lifeboat-Windows-x64-Portable.zip`, extract it completely, and
run `Codex-Lifeboat.exe`.

The executable remains unsigned. Keep an independent recovery copy and leave
Codex fully closed while making or restoring a backup.
