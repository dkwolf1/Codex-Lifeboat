# Codex Lifeboat 3.4.3 — betrouwbaardere back-ups met actieve plugins

[English](../../releases/v3.4.3.md)

Codex Lifeboat 3.4.3 is een gerichte betrouwbaarheidsupdate voor Windows 10/11.
Het eenvoudige doel blijft hetzelfde: Codex-projecten, chats, instellingen en
bijbehorende lokale gegevens veilig meenemen tussen computers.

## Wat is gewijzigd

- Nieuwe back-ups sluiten de computerspecifieke `.codex/plugins`-downloadcache
  en actieve plugin-runtime uit, zodat vergrendelde pluginbestanden de back-up
  niet meer stoppen.
- Plugininstellingen en zelfgemaakte skills blijven inbegrepen en overdraagbaar.
- Herstel negeert plugin-runtimegegevens uit oudere back-ups en behoudt de lokale
  plugin-runtime van de doelcomputer.
- Historische tijdelijke chatbijlagen waarvoor Windows geen leestoegang meer
  geeft, worden gemeld als aandachtspunt in plaats van de hele back-up te stoppen.
- Bestaande back-upformaten blijven ondersteund.

## Downloaden

Download `Codex-Lifeboat-Windows-x64-Portable.zip`, pak het bestand volledig uit
en start `Codex-Lifeboat.exe`. Start het programma niet vanuit het ZIP-bestand.

Dit blijft een openbare testrelease. Bewaar onvervangbare gegevens ook apart en
meld onverwachte resultaten via GitHub Issues.
