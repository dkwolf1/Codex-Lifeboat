# Codex Lifeboat 3.4.12 — fixes voor de Windows-back-upvoorvertoning

[English](../../releases/v3.4.12.md)

Deze update pakt beide Windows-back-upfouten uit [issue #13](https://github.com/dkwolf1/Codex-Lifeboat/issues/13) aan.

- De voorvertoning en de kopie herkennen gereserveerde Windows-apparaatnamen
  zoals `NUL` en `NUL.txt` vóór het pad wordt benaderd. Overgeslagen paden
  staan in het activiteitenlogboek en in `reports/backup-report.json`. Als
  het om een map gaat, wordt ook de inhoud overgeslagen. Hernoem het pad veilig
  aan de bron vóór het maken van de back-up als je die inhoud nodig hebt.
- De socket- en lockmap `.codex/app-server-control` wordt vóór de
  metadatacontrole overgeslagen om Windows-fout 1920 te voorkomen. Bij herstel
  blijft de eigen runtime-map op de doel-pc behouden. Een gelijknamige
  submap in een project gaat gewoon mee.
- De vervanging van de herstelde sessie-index wordt kort opnieuw geprobeerd
  als Windows tijdelijk toegang weigert.

De regressietests gebruiken echte gereserveerde NTFS-namen en simuleren
Windows-fout 1920. Pak `Codex-Lifeboat-Windows-x64-Portable.zip` volledig
uit en start `Codex-Lifeboat.exe`.
