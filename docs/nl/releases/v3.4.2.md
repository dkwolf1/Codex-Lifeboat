# Codex Lifeboat 3.4.2 — duidelijkere interface en paddetails

[English](../../releases/v3.4.2.md)

Codex Lifeboat 3.4.2 houdt hetzelfde eenvoudige doel: Codex-projecten, chats,
instellingen en bijbehorende lokale gegevens veilig meenemen tussen computers
met Windows 10/11.

## Wat is gewijzigd

- Een vernieuwd professioneel dashboard maakt back-up, herstel, controles,
  herstelpunten en diagnose gemakkelijker vindbaar.
- Resultaten tonen duidelijkere kaarten voor status, projecten, chats en omvang.
- Meldingen over overdraagbaarheid leggen uit welke lokale padverwijzingen worden
  vertaald, bewaard, als computerspecifiek worden uitgesloten of aandacht vragen.
- Onbekende padverwijzingen blijven behouden en blokkeren een geldige back-up of
  herstelactie niet; alleen een oude koppeling kan na verhuizing aandacht vragen.
- Volledige lokale paden blijven privé en worden uit opgeslagen rapporten gehaald.
- De titel in het zijmenu blijft zichtbaar bij Windows-beeldschaling.

## Downloaden

Download `Codex-Lifeboat-Windows-x64-Portable.zip`, pak het bestand volledig uit
en start `Codex-Lifeboat.exe`. Start het programma niet vanuit het ZIP-bestand.

Dit blijft een openbare testrelease. Bewaar onvervangbare gegevens ook apart en
meld onverwachte resultaten via GitHub Issues.
