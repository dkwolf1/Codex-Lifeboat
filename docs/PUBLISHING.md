# Public repository publishing metadata

Use the following metadata when publishing the repository so it is easy to find.

## Recommended repository name

`codex-transfer-assistant`

## Recommended description

One-click Codex backup, restore and Windows PC migration tool for projects, local chats, skills and settings.

## Recommended GitHub topics

`codex`, `codex-backup`, `codex-restore`, `codex-migration`, `chat-backup`,
`project-backup`, `windows`, `windows-11`, `usb-backup`, `backup`, `restore`,
`migration-tool`, `sqlite`, `disaster-recovery`

## Publishing checklist

- Make the repository public.
- Select an explicit open-source license before inviting redistribution.
- Apply the description and topics above in the repository settings.
- Create a GitHub release for every version tag and attach the portable zip.
- Add the release checksum to the release notes.
- Enable issue reporting and keep the English README at the repository root.
- Add a social preview image when branding is available.
